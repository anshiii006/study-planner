# Study Planner 

A simple and responsive Study Planner web application built using **HTML, CSS, and JavaScript**.

## 📸 Preview

![Screenshot](images/screenshot.png)

## Features

- Add and manage study tasks
- Organize daily study activities
- Track completed tasks
- Simple and user-friendly interface
- Responsive design for different screen sizes

## Technologies Used

- HTML5
- CSS3
- JavaScript
